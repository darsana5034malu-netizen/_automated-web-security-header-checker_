# Automated Web Security Header Checker

## Project Overview
This project is a Python-based cybersecurity tool that checks
HTTP security headers on a website.

## Objectives
- Identify selected security headers.
- Report which headers are present or missing.
- Provide basic security recommendations.
- Understand website security configurations.

## Technologies Used
- Python 3
- urllib
- HTTP security headers

## Requirements
Python 3 is required.
No external Python packages are needed.

## How to Run
1. Open Command Prompt in the project folder.
2. Run:

   py security_header_cheaker.py

3. Enter a website URL when prompted.
4. Review the security header report.

## Security Notice
Only check websites you are authorized to assess.
Missing headers alone do not prove a website is vulnerable.
